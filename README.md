# Yoinks Music

> Senior-friendly high taste mobile music player and discography discovery.

## Overview
Yoinks Music is an accessible, ultra-clean mobile web and Android application crafted for discovering artist discographies and listening to curated preview tracks with frictionless, touch-friendly ergonomic controls.

## Tech Stack
- **Framework:** React 18 + TypeScript + Vite
- **Styling:** Tailwind CSS + PostCSS + Autoprefixer
- **Icons:** Lucide React
- **Mobile Target:** Optimized for mobile touch & safe-area viewports (Capacitor / Mobile Web)

## Getting Started

### Development
```bash
npm install
npm run dev
```

### Production Build
```bash
npm run build
npm run preview
```
